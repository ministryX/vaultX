Security model

Zero knowledge by design, not by promise

VaultX has no server that could be breached and nothing to log. Your master password never leaves your browser, and everything stored or synced is encrypted.

Encryption

Envelope encryption, item by item

Your master password unlocks a random vault key. That key — never your password — encrypts your data, so it can be rotated at any time.

  • Argon2id key derivation (memory-hard, tunable cost).
  • AES-256-GCM with keys derived by HKDF for items, settings and sync.
  • Each item is encrypted separately and bound to its id, type, revision and trash state — records cannot be swapped or replayed.
  • Key rotation re-encrypts everything, safely across synced devices.

Defense in depth

What VaultX does — and never does

No server, no telemetry

There is no VaultX backend. The only network access is Google's APIs, and only if you enable Drive sync.

Strict extension CSP

No remote code, no eval, a single allowlisted network module, and static security checks in CI.

Pages can't peek

In-page UI lives in closed shadow roots; fills go only to the exact origin; clickjacking checks on every click.

Throttled unlock

Wrong passwords and authenticator codes are throttled and persisted across restarts.

Rollback protection

Sync refuses older or tampered vault files; snapshots are authenticated with the vault key.

Published audits

Internal adversarial reviews (v0.5, v0.7, v0.8): every finding is listed with its fix and regression test.
